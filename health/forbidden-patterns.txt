# Patterns that must never appear in a shipped file.
#
# This is the sanitization gate. It is a TEST, not a cleanup step: the plugin is
# extracted from a private working repo, and a cleanup someone does once will rot
# the first time a file is copied across. Check 6 in check-all.py fails the build
# on any match, and CI runs it on every push.
#
# One regex per line, case-insensitive. Lines starting with # are comments.
# Keep each pattern narrow — a pattern broad enough to match ordinary prose makes
# the gate noisy, and a noisy gate gets disabled.
